# 확장 C 기능 명세서 — QR코드로 휴대폰에 받기 (`04-qr-share.md`)

이 문서는 기획 에이전트(`planner`)가 **확장 C ("QR코드로 휴대폰에 받기")** 기능을 비전공자도 쉽게 이해할 수 있도록 정리한 기획서입니다.

---

## 1. 목표
- 완성된 인생네컷 세로 프레임 사진을 **Supabase Storage(인터넷 파일 금고)의 `photos` 공개 버킷(사진 보관함)**에 올리고, 누구나 로그인 없이 열 수 있는 공개 인터넷 주소를 **QR코드**로 화면에 보여 주어 휴대폰으로 바로 받아 저장하게 한다.

---

## 2. 사용자 이야기 (누가 어떤 상황에서 어떻게 쓰는가)
- **버튼 한 번으로 QR코드 만들기**: 촬영과 필터 선택을 마친 뒤 결과 화면에서 **[QR코드로 휴대폰에 받기]** 버튼을 누르면, `"사진을 올리는 중이에요..."` 안내와 함께 완성된 세로 프레임 사진이 인터넷 파일 금고(`photos` 공개 버킷)에 올라가고 화면에 네모난 QR코드가 나타납니다.
- **로그인 없이 바로 열고 길게 눌러 저장**: 사진을 받는 사람은 회원가입이나 로그인 없이 휴대폰 기본 카메라로 화면의 QR코드를 비추기만 하면 사진 주소를 바로 열 수 있고, 열린 사진을 길게 눌러 휴대폰 사진첩에 저장할 수 있습니다. 컴퓨터에서도 아래의 **[새 창으로 사진 열기]** 링크를 눌러 바로 확인할 수 있습니다.
- **직접 지우기 전까지 사진 보관**: 올라간 사진은 자동으로 사라지지 않으며, 프로젝트 주인(학생)이 Supabase 보관함에서 직접 지우기 전까지 그대로 보관됩니다.
- **필터를 바꾸면 기존 QR 숨김**: 다른 필터 버튼을 눌러 사진 색감을 바꾸면, 이전 필터 사진으로 만든 옛날 QR코드 상자는 자동으로 숨겨지고 **[QR코드로 휴대폰에 받기]** 버튼이 다시 활성화되어 바뀐 필터 사진으로 새 QR코드를 만들 수 있습니다.

---

## 3. 화면 흐름

1. **결과 화면 확인 (`section#result-section`)**
   - 완성된 세로 프레임 사진(`img#result-photo`) 아래에 **[QR코드로 휴대폰에 받기]** 버튼(`button#qr-btn`)이 보입니다.
   - 안내 문장(`p#qr-message`)은 비어 있고, QR코드 상자(`div#qr-box`)는 처음에 숨겨져(`class="hidden"`) 있습니다.
2. **[QR코드로 휴대폰에 받기] 버튼 누르기**
   - 중복해서 눌리지 않도록 버튼이 잠기고, 안내 문장(`p#qr-message`)에 **`"사진을 올리는 중이에요..."`**가 표시됩니다.
   - 업로드가 성공하면 안내 문장이 정리되고 숨겨져 있던 QR 상자(`div#qr-box`)가 나타납니다.
   - QR 상자 안에는 **`"휴대폰 카메라로 QR코드를 비춰 보세요"`**, `200×200` 크기의 QR코드(`div#qrcode`), **`"열린 사진을 길게 눌러 저장하세요"`**, 그리고 새 창으로 열리는 사진 링크(`a#photo-link`)가 표시됩니다.
   - 만약 설정값 미입력이나 인터넷 오류 등으로 실패하면 **`"올리지 못했어요: (오류 문장)"`**을 `p#qr-message`에 띄우고 버튼을 다시 풀어 줍니다.
3. **필터 바꾸기 또는 [처음으로] 누르기**
   - 위쪽 필터 버튼을 눌러 필터를 바꾸면 `renderResult()`가 실행되면서 새로 합쳐진 프레임 캔버스가 `state.strip`에 저장되고, 기존 QR 상자(`div#qr-box`)는 다시 숨겨지며 **[QR코드로 휴대폰에 받기]** 버튼이 다시 풀립니다.

## 4. 완료 기준 체크리스트 (예 / 아니오 확인용)

검수 에이전트(`reviewer`)와 사용자가 눈으로 보고 **"예 / 아니오"**로 확인할 수 있는 기준입니다.

- [ ] **1.** 결과 화면의 사진 아래에 **[QR코드로 휴대폰에 받기]** 버튼(`button#qr-btn`), 안내 문장(`p#qr-message`), 처음에는 숨겨진 QR 상자(`div#qr-box.hidden`)가 있는가? **(예 / 아니오)**
- [ ] **2.** **[QR코드로 휴대폰에 받기]** 버튼을 누르면 버튼이 잠기고 `"사진을 올리는 중이에요..."` 안내가 나온 뒤, Supabase Storage의 `photos` 공개 버킷에 사진이 올라가고 `200×200` QR코드(`div#qrcode`)와 새 창 링크(`a#photo-link`)가 담긴 QR 상자가 나타나는가? **(예 / 아니오)**
- [ ] **3.** 받는 사람이 휴대폰 카메라로 QR코드를 비추거나 링크를 눌렀을 때 **로그인 없이** 완성된 사진이 바로 열리며, 학생이 직접 지우기 전까지 사진이 보관되는가? **(예 / 아니오)**
- [ ] **4.** 필터 버튼을 눌러 다른 필터로 바꾸면 **기존에 열려 있던 QR 상자가 숨겨지고** **[QR코드로 휴대폰에 받기]** 버튼이 다시 눌릴 수 있게 풀리는가? **(예 / 아니오)**
- [ ] **5.** 업로드에 실패했을 때 `"올리지 못했어요: (오류 문장)"`이 `p#qr-message`에 표시되고 버튼 잠금이 다시 풀리는가? **(예 / 아니오)**

---

## 5. 이번에 하지 않을 것 (범위 밖 기능)

- ❌ **자동 삭제 타이머 서버 기능**: 사진은 일정 시간 뒤 자동 삭제하지 않고 학생이 Supabase 대시보드에서 직접 지우기 전까지 보관합니다.
- ❌ **회원가입 및 로그인 화면**: 포토부스 사용자와 사진 받는 사람 모두 별도 로그인 없이 바로 이용합니다.

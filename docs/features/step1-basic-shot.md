# 1단계 기능 명세서 — 기본 촬영 (`step1-basic-shot.md`)

이 문서는 기획 에이전트(`planner`)가 **1단계(기본 촬영: 5초 카운트다운 후 사진 1장 촬영 및 확인)**의 요구사항을 비전공자도 쉽게 읽을 수 있도록 정리한 기능 명세서입니다.

---

## 1. 목표
- 웹페이지를 열면 카메라 화면을 보여주고, **[촬영하기]** 버튼을 누르면 **5초 카운트다운(`5 → 4 → 3 → 2 → 1`)** 후 **사진 1장을 촬영**하여 화면에서 바로 **결과를 확인**하거나 **[다시 찍기]**를 할 수 있게 만든다.

---

## 2. 사용자 이야기 (누가 어떤 상황에서 어떻게 쓰는가)
- **거울처럼 먼저 확인하기**: 사용자는 스마트폰 세로 화면(또는 컴퓨터)으로 포토부스 웹페이지를 열자마자 실시간 카메라 화면을 보며 머리 모양과 표정을 정돈합니다.
- **5초 동안 여유 있게 포즈 취하기**: 준비가 되어 **[촬영하기]** 버튼을 누르면 화면에 `5, 4, 3, 2, 1` 숫자가 1초씩 크게 줄어들며 나타나므로, 손을 내리고 자연스럽게 포즈를 잡을 수 있습니다.
- **찍힌 사진 바로 보고 다시 찍기**: 5초가 지나 사진 1장이 찍히면 방금 찍힌 내 사진이 결과 화면에 크게 나타나고, 표정이 아쉬우면 **[다시 찍기]** 버튼을 눌러 처음부터 다시 촬영할 수 있습니다.
- **문제가 생겨도 당황하지 않기**: 만약 카메라 권한을 허용하지 않았거나 카메라가 없는 기기라면, 화면에 친절한 한국어 안내 문구가 나와 어떻게 해야 하는지 바로 알 수 있습니다.

---

## 3. 화면 흐름 (6단계 기능 순서)

사용자가 겪는 화면 변화와 동작 순서는 아래 6단계로 진행됩니다.

| 순서 | 단계 이름 | 화면에서 일어나는 일 (동작 설명) |
| :---: | :--- | :--- |
| **1** | **카메라 화면 보여주기** | 웹페이지가 열리면 기기의 카메라를 연결해 실시간 영상(`<video>`, 카메라 화면을 비추는 영역)을 휴대폰 세로 화면 가운데에 보여줍니다. |
| **2** | **촬영 버튼 누르기** | 사용자가 카메라 화면 아래에 있는 **[촬영하기]** 버튼을 누릅니다. (카운트다운 중 중복 클릭을 막기 위해 버튼은 잠시 비활성화됩니다.) |
| **3** | **5초 카운트다운** | 화면에 **`5 → 4 → 3 → 2 → 1`** 숫자가 1초 간격으로 크게 표시됩니다. |
| **4** | **사진 1장 촬영** | 카운트다운이 끝나는 순간 현재 카메라 화면의 한 장면을 순간 포착해 `Canvas`(브라우저 안의 투명 도화지)에 사진 1장으로 그대로 옮겨 그립니다. |
| **5** | **촬영 결과 확인** | 카메라 촬영 화면을 숨기고(`class="hidden"`), 방금 찍은 사진 도화지(`canvas`)가 담긴 **결과 확인 화면**을 보여줍니다. |
| **6** | **다시 찍기** | 결과 화면에서 **[다시 찍기]** 버튼을 누르면 결과 화면을 다시 숨기고(`class="hidden"`), 1번 **카메라 화면 보여주기** 상태로 돌아갑니다. |

---

## 4. 필요한 버튼

1단계 화면에 들어가는 버튼 목록입니다. 휴대폰 세로 화면에서 엄지손가락으로 누르기 편한 크기로 배치합니다.

| 버튼 이름 (화면에 적힐 글자) | 보이는 시점 | 누르면 하는 일 |
| :--- | :--- | :--- |
| **[촬영하기]** | 촬영 대기 화면 (카메라가 켜진 뒤) | 5초 카운트다운(`5 → 4 → 3 → 2 → 1`)을 시작하고, 끝나면 사진 1장을 찍어 결과 화면으로 넘어갑니다. |
| **[다시 찍기]** | 촬영 결과 확인 화면 | 방금 찍은 결과 화면을 숨기고(`class="hidden"`), 다시 실시간 카메라 촬영 대기 화면으로 돌아갑니다. |

---

## 5. 안내 문구 (상태별·오류별 한국어 안내)

사용자가 현재 어떤 상태인지 알기 쉽게 화면에 표시할 한국어 문구입니다.

| 상황 | 화면에 보여줄 한국어 안내 문구 |
| :--- | :--- |
| **카메라 연결 중** | `"카메라를 연결하고 있어요. 잠시만 기다려 주세요..."` |
| **촬영 대기 중 (정상 연결)** | `"화면을 보고 포즈를 준비한 뒤 [촬영하기] 버튼을 눌러 주세요!"` |
| **5초 카운트다운 중** | `"포즈를 취해 주세요! 곧 사진이 찍힙니다."` (화면 중앙에 `5`, `4`, `3`, `2`, `1` 큰 숫자 표시) |
| **촬영 결과 확인 중** | `"사진이 완성되었어요! 마음에 들지 않으면 [다시 찍기]를 눌러 주세요."` |
| **오류: 카메라 권한 거부 또는 연결 실패** | `"카메라를 사용할 수 없습니다. 브라우저 주소창 옆에서 카메라 권한을 '허용'으로 바꾸거나, 안전한 주소(https 또는 localhost)에서 다시 열어 주세요."` |

---

## 6. 완료 기준 체크리스트 (예 / 아니오 확인용)

검수 에이전트(`reviewer`)와 사용자가 눈으로 직접 보고 **"예 / 아니오"**로 판정할 수 있는 완료 기준입니다.

- [ ] **1. [카메라 화면 보여주기]** 웹페이지를 열었을 때 휴대폰 세로 화면 비율에 맞춘 실시간 카메라 화면이 가운데에 보이는가? **(예 / 아니오)**
- [ ] **2. [오류 안내 문구]** 카메라 권한을 거부하거나 카메라가 없을 때, 화면 안에 한국어 오류 안내 문구가 나타나는가? **(예 / 아니오)**
- [ ] **3. [촬영 버튼 누르기]** 카메라 화면 아래에 **[촬영하기]** 버튼이 잘 보이고, 촬영 중에는 중복으로 눌리지 않게 막히는가? **(예 / 아니오)**
- [ ] **4. [5초 카운트다운]** **[촬영하기]** 버튼을 누르면 화면에 `5, 4, 3, 2, 1` 숫자가 1초 간격으로 차례대로 표시되는가? **(예 / 아니오)**
- [ ] **5. [사진 1장 촬영 및 결과 확인]** 5초 카운트다운이 끝나면 카메라 화면이 숨겨지고(`class="hidden"`), 찍힌 사진 1장이 결과 화면(`canvas`)에 선명하게 나타나는가? **(예 / 아니오)**
- [ ] **6. [다시 찍기]** 결과 화면에서 **[다시 찍기]** 버튼을 누르면 결과 화면이 숨겨지고 다시 실시간 카메라 촬영 화면으로 돌아가는가? **(예 / 아니오)**

# 확장 A 기능 명세서 — 2컷/4컷 프레임 선택 후 연속 촬영 (`02-cut-select.md`)

이 문서는 기획 에이전트(`planner`)가 **확장 A ("2컷/4컷 프레임 선택 후 그 수만큼 촬영")** 기능을 비전공자도 쉽게 이해할 수 있도록 정리한 기획서입니다.

---

## 1. 목표
- 사용자가 **2컷 또는 4컷 프레임**을 먼저 고르면, **[촬영 시작]** 버튼 한 번으로 **선택한 컷 수만큼 5초 카운트다운 촬영(컷 사이 0.7초 쉬기)**이 자동으로 이어지고, 찍힌 사진들을 **흰 바탕 세로 프레임 한 장(하단에 `'인생네컷'`과 오늘 날짜 표시)**으로 합쳐 보여준다.

---

## 2. 사용자 이야기 (누가 어떤 상황에서 어떻게 쓰는가)
- **직관적인 컷 수 고르기 (화면 ①)**: 사용자는 처음 화면에서 **작은 2칸짜리 프레임 그림이 그려진 [2컷] 버튼**과 **작은 4칸짜리 프레임 그림이 그려진 [4컷] 버튼**을 보고 오늘 찍고 싶은 장수를 한눈에 고릅니다.
- **자동 연속 촬영과 작은 미리보기 (화면 ②)**: 촬영 화면에서 **[촬영 시작]** 버튼을 한 번만 누르면 `5, 4, 3, 2, 1` 5초 카운트다운 뒤 사진이 찍히고, **0.7초 잠깐 숨을 고른 뒤** 다음 컷 카운트다운이 자동으로 이어집니다. 이때 화면에 **`"1 / 4"`(또는 `"1 / 2"`) 진행 표시**가 바뀌고, 방금 찍힌 사진이 아래쪽 **작은 미리보기(썸네일)** 칸에 한 장씩 차곡차곡 채워져 몇 장 찍혔는지 바로 알 수 있습니다.
- **오늘 날짜가 적힌 세로 프레임 확인 (화면 ③)**: 마지막 컷까지 촬영이 끝나면 **흰 바탕의 세로 프레임 한 장**에 `4:3` 비율 사진들이 위에서부터 순서대로 들어가고, 맨 아래에 **`'인생네컷'` 글자와 오늘 날짜(예: `2026. 11. 16`)**가 함께 찍힌 완성본을 확인합니다. **[처음으로]** 버튼을 누르면 다시 컷 수 고르기 화면(화면 ①)으로 돌아갑니다.

---

## 3. 화면 흐름 (화면 ① → 화면 ② → 화면 ③)

| 순서 | 화면 이름 | 화면 구성 및 동작 설명 |
| :---: | :--- | :--- |
| **화면 ①** | **컷 수 고르기** | - **[2컷]** 버튼과 **[4컷]** 버튼이 나란히 보이며, 각 버튼 안에는 **2칸 / 4칸 모양의 작은 프레임 그림**이 함께 표시됩니다.<br>- 사용자가 원하는 컷 수 버튼을 누르면 선택된 컷 수(`2` 또는 `4`)를 기억하고 **화면 ②(촬영 화면)**로 넘어갑니다. |
| **화면 ②** | **촬영** | - 실시간 카메라 화면과 함께 현재 촬영 진행 상태를 알려 주는 **`"1 / 2"` 또는 `"1 / 4"` 진행 표시**가 보입니다.<br>- 카메라 아래에는 방금 찍은 사진들이 순서대로 들어갈 **작은 미리보기(썸네일) 영역**과 **[촬영 시작]** 버튼이 있습니다.<br>- **[촬영 시작]** 버튼을 **한 번** 누르면 선택한 컷 수만큼 **`5초 카운트다운(5 → 4 → 3 → 2 → 1) → 찰칵(작은 미리보기에 추가) → 0.7초 쉬기`**가 자동으로 반복됩니다.<br>- 마지막 컷까지 다 찍히면 세로 프레임을 만들어 **화면 ③(결과 화면)**으로 넘어갑니다. |
| **화면 ③** | **결과** | - **흰 바탕 세로 프레임 한 장**이 화면에 크게 표시됩니다.<br>- 프레임 안에는 찍은 사진들이 **`4:3` 가로세로 비율** 그대로 위에서부터 차례대로 배치되고, 프레임 맨 아래 여백에는 **`'인생네컷'` 글자와 오늘 날짜(예: `2026. 11. 16`)**가 적혀 있습니다.<br>- 아래의 **[처음으로]** 버튼을 누르면 찍은 사진과 진행 상태를 비우고 다시 **화면 ①(컷 수 고르기)**로 돌아갑니다. |

---

## 4. 완료 기준 체크리스트 (예 / 아니오 확인용)

검수 에이전트(`reviewer`)와 사용자가 눈으로 직접 보고 **"예 / 아니오"**로 판정할 수 있는 기준입니다.

- [ ] **1. [화면 ① — 컷 수 고르기]** 첫 화면에 작은 프레임 그림이 들어간 **[2컷]** 버튼과 **[4컷]** 버튼이 보이고, 누르면 촬영 화면(화면 ②)으로 넘어가는가? **(예 / 아니오)**
- [ ] **2. [화면 ② — 자동 연속 촬영 및 0.7초 쉬기]** **[촬영 시작]** 버튼을 한 번만 누르면 선택한 컷 수(2장 또는 4장)만큼 **5초 카운트다운 촬영**이 자동으로 이어지며, 각 컷 촬영 사이에 **0.7초 쉬기(대기)**가 동작하는가? **(예 / 아니오)**
- [ ] **3. [화면 ② — 진행 표시 및 작은 미리보기]** 촬영이 진행될 때 `"1 / 4"`(2컷일 때는 `"1 / 2"`)처럼 **현재 진행 표시**가 바뀌고, 찍은 사진이 화면의 **작은 미리보기** 칸에 한 장씩 나타나는가? **(예 / 아니오)**
- [ ] **4. [화면 ③ — 흰 바탕 세로 프레임 합성]** 결과 화면에 **흰 바탕 세로 프레임 한 장**이 나타나며, 그 안에 **`4:3` 비율 사진들**이 위에서부터 순서대로 찌그러짐 없이 들어가 있는가? **(예 / 아니오)**
- [ ] **5. [화면 ③ — 하단 문구와 오늘 날짜]** 완성된 세로 프레임 아래쪽에 **`'인생네컷'` 글자와 오늘 날짜**가 함께 적혀 있는가? **(예 / 아니오)**
- [ ] **6. [화면 ③ — 처음으로 버튼]** 결과 화면에서 **[처음으로]** 버튼을 누르면 다시 **화면 ①(컷 수 고르기)**로 깨끗하게 돌아가는가? **(예 / 아니오)**

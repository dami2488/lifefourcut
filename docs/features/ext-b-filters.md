# 확장 B 기능 명세서 — 사진 색상 필터 입히기 (`ext-b-filters.md`)

이 문서는 기획 에이전트(`planner`)가 **확장 B(사진 색상 필터 입히기)**에서 만들 기능을 비전공자도 쉽게 이해할 수 있도록 정리한 기획서입니다.

---

## 1. 목표
- 4컷 연속 촬영이 끝난 결과 화면에서 사용자가 **원하는 분위기 필터(원본, 흑백, 따뜻한 느낌, 차가운 느낌)를 골라 사진에 바로 적용하고, 필터가 적용된 4컷 세로 프레임을 PNG로 내려받을 수 있게 만든다.**

---

## 2. 사용자 이야기 (누가 어떤 상황에서 어떻게 쓰는가)
- **다양한 분위기 비교해 보기**: 사용자는 4컷 촬영이 끝난 뒤 결과 화면에서 **[원본]**, **[흑백]**, **[따뜻한 톤]**, **[차가운 톤]** 버튼을 차례대로 눌러 보며 오늘 찍은 사진에 가장 잘 어울리는 색감을 고릅니다.
- **프레임은 깨끗한 흰색 그대로 유지**: 흑백이나 따뜻한 필터를 골라도, 사진 바깥쪽의 **흰색 프레임과 하단 `'인생네컷'` 글자는 변색되지 않고 깨끗한 상태 그대로 유지**되어 실제 포토부스 인화지처럼 예쁘게 보입니다.
- **필터가 입혀진 사진 그대로 저장**: 마음에 드는 필터를 고른 뒤 **[PNG로 사진 다운로드]** 버튼을 누르면 화면에서 본 필터 효과가 그대로 들어간 4컷 사진 파일이 저장됩니다.

---

## 3. 화면 흐름

1. **4컷 촬영 완료 직후 (기본 상태)**
   - 결과 화면에 **원본(`original`)** 색상의 4컷 세로 프레임이 표시됩니다.
   - 결과 사진 바로 아래에 필터 선택 버튼 4개(**[원본]**, **[흑백]**, **[따뜻한 톤]**, **[차가운 톤]**)가 나란히 보이며, 처음에는 **[원본]** 버튼이 선택된 상태(강조 표시)로 나타납니다.
2. **필터 버튼 누르기**
   - 사용자가 원하는 필터 버튼을 누르면, 찍어 둔 4장의 사진 각각에 해당 색상 필터(`applyFilter(canvas, filterName)`)가 입혀진 뒤 다시 세로 프레임(`makeStrip`)으로 합쳐져 화면의 결과 도화지(`#result-canvas`)에 즉시 나타납니다.
   - 언제든 **[원본]**이나 다른 필터 버튼을 다시 누르면 화질 손실 없이 원래 찍은 사진에서 새 필터로 깔끔하게 바뀝니다.
3. **PNG 다운로드 또는 다시 찍기**
   - **[PNG로 사진 다운로드]**를 누르면 현재 선택된 필터가 적용된 4컷 세로 프레임이 PNG로 저장됩니다.
   - **[다시 찍기]**를 누르면 필터 선택이 **[원본]**으로 초기화되고 카메라 촬영 화면으로 돌아갑니다.

---

## 4. 완료 기준 체크리스트 (예 / 아니오 확인용)

검수 에이전트(`reviewer`)와 사용자가 눈으로 직접 보고 **"예 / 아니오"**로 판정할 수 있는 기준입니다.

- [ ] **1.** 4컷 촬영 결과 화면에 **[원본]**, **[흑백]**, **[따뜻한 톤]**, **[차가운 톤]** 필터 선택 버튼이 잘 보이는가? **(예 / 아니오)**
- [ ] **2.** 각 필터 버튼을 누를 때마다 현재 선택된 버튼이 눈에 띄게 표시되고, 결과 화면의 4컷 사진 색감이 즉시 바뀌는가? **(예 / 아니오)**
- [ ] **3.** 여러 번 다른 필터를 번갈아 눌러도 화질이 깨지지 않고 **[원본]**을 누르면 처음 찍은 색상으로 깨끗하게 돌아오는가? **(예 / 아니오)**
- [ ] **4.** 필터를 적용했을 때 사진 4장의 색감만 바뀌고, 바깥쪽 흰색 프레임과 하단 `'인생네컷'` 글자는 깨끗하게 유지되는가? **(예 / 아니오)**
- [ ] **5.** 아이폰 Safari에서도 필터 효과가 정상적으로 적용되며, **[PNG로 사진 다운로드]** 시 필터가 적용된 사진이 저장되는가? **(예 / 아니오)**

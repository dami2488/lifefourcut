# 확장 B 기능 명세서 — 사진 색상 필터 (`03-filters.md`)

이 문서는 기획 에이전트(`planner`)가 **확장 B ("완성 화면에서 6가지 사진 필터 적용하기")** 기능을 비전공자도 쉽게 이해할 수 있도록 정리한 기획서입니다.

---

## 1. 목표
- 완성(결과) 화면에서 **원본·흑백·세피아·따뜻하게·시원하게·화사하게** 6가지 필터 버튼을 눌러 사진 분위기를 바로 바꾸고, **원본 사진은 그대로 둔 채 필터를 입힌 복사본으로 세로 프레임을 다시 만든다.**

---

## 2. 사용자 이야기 (누가 어떤 상황에서 어떻게 쓰는가)
- **가로 한 줄 버튼으로 쉽게 고르기**: 촬영이 끝나고 완성 화면이 나오면, 세로 프레임 사진 아래에 **[원본] [흑백] [세피아] [따뜻하게] [시원하게] [화사하게]** 6개 버튼이 가로 한 줄로 나란히 보입니다.
- **누르는 즉시 적용 및 선택 표시**: 원하는 필터 버튼을 누르면 찍은 사진 전체에 필터가 바로 적용되고, 방금 누른 버튼이 색으로 강조 표시되어 지금 어떤 필터가 걸려 있는지 한눈에 알 수 있습니다.
- **여러 번 바꿔도 화질 유지 & 깨끗한 흰 프레임**: 원본 사진(`state.shots`)은 건드리지 않고 매번 복사본에 픽셀(화면을 이루는 작은 점)의 빨강(R)·초록(G)·파랑(B) 값을 직접 계산해 입힌 뒤 세로 프레임을 다시 합치므로, 여러 번 바꿔도 화질이 나빠지지 않고 **프레임 흰 바탕과 `'인생네컷'`·날짜 글씨에는 필터가 입혀지지 않습니다.**

---

## 3. 화면 흐름

1. **촬영 완료 직후 (기본 상태)**
   - 결과 화면(`section#result-section`)에 원본 사진으로 합쳐진 세로 프레임(`img#result-photo`)이 나타나고, 가로 한 줄 필터 막대(`div#filter-bar`)에서 **[원본]** 버튼이 색으로 선택된 상태로 표시됩니다.
2. **필터 버튼 누르기 (6종)**
   - 사용자가 **[원본]**, **[흑백]**, **[세피아]**, **[따뜻하게]**, **[시원하게]**, **[화사하게]** 중 하나를 누르면:
     1. 누른 버튼에 선택 색상 스타일(`.active`)이 표시됩니다.
     2. 보관된 원본 사진 목록(`state.shots`)은 그대로 두고, 각 사진의 복사본을 만들어 `applyFilter(canvas, filterName)`으로 R·G·B 픽셀 값을 계산해 필터를 입힙니다.
     3. 필터가 입혀진 사진 복사본들로 `makeStrip(filteredShots)`을 다시 호출해 세로 프레임을 만들고 `img#result-photo`를 즉시 바꿉니다.
3. **[처음으로] 버튼 누르기**
   - **[처음으로]** 버튼을 누르면 선택된 필터가 다시 **[원본]**으로 초기화되고 첫 화면(컷 수 고르기)으로 돌아갑니다.

- [ ] **2.** 필터를 누르면 프레임 사진 전체에 바로 적용되고, 누른 버튼이 색으로 표시되는가? **(예 / 아니오)**

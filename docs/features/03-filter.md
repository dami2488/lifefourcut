# 확장 B 기능 명세서 — 촬영 후 필터 (`03-filter.md`)

이 문서는 기획 에이전트(`planner`)가 **확장 B ("촬영 후 필터")** 기능을 비전공자도 쉽게 이해할 수 있도록 정리한 기획서입니다.

---

## 1. 목표
- 촬영이 끝난 완성 화면에서 **원본, 흑백, 세피아, 따뜻하게, 시원하게, 화사하게** 6가지 필터를 눌러 바로 적용하고, **원본 사진은 그대로 둔 채 필터를 입힌 복사본으로 세로 프레임을 다시 만들어 프레임 바탕과 글씨는 그대로 유지한다.**

---

## 2. 사용자 이야기 (누가 어떤 상황에서 어떻게 쓰는가)
- **완성 화면에서 한 줄로 고르기**: 촬영이 끝나고 완성된 세로 프레임이 나오면, 그 아래에 **[원본] [흑백] [세피아] [따뜻하게] [시원하게] [화사하게]** 6개의 필터 버튼이 가로 한 줄로 보입니다.
- **고르면 바로 적용 & 선택 버튼 표시**: 원하는 필터 버튼을 누르면 찍은 사진 전체에 필터 색감이 바로 적용되고, 방금 누른 버튼이 색으로 표시됩니다.
- **원본으로 돌아가기 가능 & 깨끗한 프레임**: 필터를 여러 번 바꾸어도 원본 사진을 따로 보관하고 있어서 화질이 나빠지지 않으며, **[원본]**을 누르면 처음 찍은 그대로 돌아옵니다. 또한 사진에만 필터를 입히고 세로 프레임을 다시 합치므로 **흰 바탕과 아래 `'인생네컷'`·날짜 글씨는 색이 변하지 않고 그대로 유지됩니다.**

---

## 3. 화면 흐름

1. **촬영 완료 직후 (완성 화면 진입)**
   - 완성 화면(`section#result-section`)에 **원본(`original` / `none`)** 상태의 세로 프레임 사진(`img#result-photo`)이 보입니다.
   - 가로 한 줄 필터 버튼 묶음에서 **[원본]** 버튼이 선택된 색(`.active`)으로 표시되어 있습니다.
2. **필터 버튼 누르기 (`원본`, `흑백`, `세피아`, `따뜻하게`, `시원하게`, `화사하게`)**
   - 사용자가 원하는 필터 버튼을 누르면 누른 버튼만 선택 색으로 바뀝니다.
   - 보관해 둔 원본 사진들(`state.shots`)은 건드리지 않고, 각 사진에 필터를 입힌 새 캔버스들을 만들어 세로 프레임(`makeStrip`)으로 다시 합친 뒤 완성 사진(`img#result-photo`)에 바로 보여 줍니다.
3. **[처음으로] 버튼 누르기**
   - **[처음으로]** 버튼을 누르면 선택된 필터가 다시 **[원본]**으로 초기화되고 첫 화면(컷 수 고르기)으로 돌아갑니다.

---

## 4. 완료 기준 체크리스트 (예 / 아니오 확인용)

검수 에이전트(`reviewer`)와 사용자가 눈으로 보고 **"예 / 아니오"**로 확인할 수 있는 기준입니다.

- [ ] **1.** 완성(결과) 화면에 **원본, 흑백, 세피아, 따뜻하게, 시원하게, 화사하게** 6개 필터 버튼이 가로 한 줄로 있는가? **(예 / 아니오)**
- [ ] **2.** 필터 버튼을 누르면 세로 프레임 속 사진 전체에 바로 적용되고, 누른 버튼이 색으로 표시되는가? **(예 / 아니오)**
- [ ] **3.** 필터를 여러 번 바꿔도 화질이 나빠지지 않고, **[원본]**을 누르면 원래 사진 색감으로 돌아가는가? **(예 / 아니오)**
- [ ] **4.** 어떤 필터를 골라도 **프레임 흰 바탕과 아래 `'인생네컷'`·날짜 글씨에는 필터가 입혀지지 않고 그대로 유지되는가?** **(예 / 아니오)**

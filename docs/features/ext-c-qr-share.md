# 확장 C 기능 명세서 — 클라우드 공유 및 QR코드 전송 (`ext-c-qr-share.md`)

이 문서는 기획 에이전트(`planner`)가 **확장 C(Supabase Storage 업로드 및 QR코드 공유)**에서 만들 기능을 비전공자도 쉽게 이해할 수 있도록 정리한 기획서입니다.

---

## 1. 목표
- 완성된 인생네컷 4컷 사진을 **Supabase Storage(클라우드 파일 저장소)**의 `photos` 버킷(사진 보관함)에 올리고, 발급된 인터넷 주소를 **QR코드**로 화면에 그려 **사용자가 스마트폰 카메라로 스캔해 바로 사진을 내려받을 수 있게 만든다.**

---

## 2. 사용자 이야기 (누가 어떤 상황에서 어떻게 쓰는가)
- **컴퓨터나 태블릿에서 찍고 내 폰으로 받기**: 매장에 놓인 태블릿이나 노트북으로 친구들과 4컷 사진을 찍은 뒤, **[QR코드로 휴대폰에 받기]** 버튼을 누르면 화면에 네모난 QR코드가 나타납니다.
- **카메라로 찍기만 하면 바로 열림**: 스마트폰 기본 카메라로 화면의 QR코드를 비추면 방금 찍은 인생네컷 사진 주소가 바로 열려 내 휴대폰 사진첩에 손쉽게 저장할 수 있습니다.
- **안심할 수 있는 사진 보관 안내**: 결과 화면에 사진이 어떻게 보관되고 쓰이는지 알려 주는 **사진 보관 정책 안내 문구**가 함께 표시되어 안심하고 이용할 수 있습니다.
- **설정 전이나 오류 시에도 친절한 안내**: 만약 아직 Supabase 연결 주소나 키를 넣지 않았거나 인터넷 연결에 문제가 생기면, 화면 안에 쉬운 한국어로 어떻게 설정하면 되는지 안내해 줍니다.

---

## 3. 화면 흐름

1. **결과 확인 화면 (4컷 촬영 및 필터 선택 뒤)**
   - 완성된 4컷 세로 프레임 아래에 **[PNG로 사진 다운로드]**, **[QR코드로 휴대폰에 받기]**, **[다시 찍기]** 버튼이 보입니다.
   - QR코드가 그려질 상자(`#qr-section`)는 처음에는 숨겨져 있습니다(`class="hidden"`).
2. **[QR코드로 휴대폰에 받기] 버튼 누르기**
   - 버튼을 누르면 중복 클릭을 막기 위해 버튼이 잠시 잠기고, `"사진을 클라우드에 올리고 QR코드를 만들고 있어요..."` 안내가 표시됩니다.
   - 현재 화면의 결과 도화지(`#result-canvas`, 선택된 필터까지 반영된 상태)를 이미지 파일로 바꿔 Supabase Storage의 `photos` 버킷에 업로드(`uploadPhoto(canvas)`)합니다.
3. **QR코드 및 사진 보관 정책 표시**
   - 업로드가 끝나고 사진의 공개 인터넷 주소(`url`)를 받아오면, 숨겨져 있던 QR코드 영역(`#qr-section`)을 열고 그 안에 선명한 QR코드(`drawQrCode(element, url)`)와 **사진 보관 정책 안내 문구**를 함께 보여줍니다.
4. **필터 변경 또는 다시 찍기 시 초기화**
   - 다른 필터 버튼을 누르거나 **[다시 찍기]**를 누르면 이전에 만든 QR코드 영역은 다시 숨겨집니다(`class="hidden"`).

## 4. 완료 기준 체크리스트 (예 / 아니오 확인용)

검수 에이전트(`reviewer`)와 사용자가 눈으로 직접 보고 **"예 / 아니오"**로 판정할 수 있는 기준입니다.

- [ ] **1.** 결과 화면에 **[QR코드로 휴대폰에 받기]** 버튼과 **사진 보관 정책 안내 문구**가 준비되어 있는가? **(예 / 아니오)**
- [ ] **2.** 외부 도구(Supabase 및 QR코드 생성 라이브러리)를 설치 도구 없이 `index.html`에서 **CDN 링크**(인터넷 주소)로만 불러왔는가? **(예 / 아니오)**
- [ ] **3.** `js/config.js`에 관리자용 비밀 키(`sb_secret_...` 또는 `service_role`)를 절대 쓰지 않고 공개용 키(`Publishable key` / `anon` 키)만 쓰도록 안내되어 있는가? **(예 / 아니오)**
- [ ] **4.** `js/upload.js`에 설계도의 함수 이름 그대로 `uploadPhoto(canvas)`와 `drawQrCode(element, url)` 두 함수가 한국어 주석과 함께 구현되어 있는가? **(예 / 아니오)**
- [ ] **5.** Supabase 설정 완료 후 **[QR코드로 휴대폰에 받기]**를 누르면 `photos` 버킷에 사진이 올라가고 화면에 스캔 가능한 QR코드가 나타나는가? **(예 / 아니오)**
- [ ] **6.** 아직 Supabase 설정값을 넣지 않았거나 업로드 오류가 났을 때, 화면 안에 친절한 한국어 안내 문구가 표시되는가? **(예 / 아니오)**

## 5. 이번에 하지 않을 것

- ❌ **복잡한 서버 프로그램이나 회원가입·로그인 기능**: 누구나 별도 로그인 없이 포토부스에서 바로 찍고 QR코드로 받아 갈 수 있도록 단순하고 직관적인 구조만 유지합니다.
- ❌ **터미널 `git` 명령어 사용**: 배포 안내 시 터미널 명령어 대신 GitHub 웹사이트의 파일 업로드(`Add file → Upload files`) 방식만 사용합니다.
